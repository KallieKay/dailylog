# Daily Flow

WTC-DPY46VVK

A study session and habit tracking web application built with React, TypeScript, and Vite.

## Features

- **Subjects Management**: Track subjects with weekly study hour goals.
- **Session Logging**: Log daily study sessions with minutes and notes mapped to subjects.
- **Habit Tracking**: Daily habit check-in list with instant visual feedback and completion state.
- **Weekly Progress Summary**:
  - Total study hours aggregated by subject for the current week.
  - Habit completion rates and percentages across the last 7 days.
- **Persistent Storage**: Data automatically saved to local storage so progress is preserved across sessions.
- **Clean Responsive UI**: Designed with clean typography, responsive layout, and gradient styling.

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Tooling**: Vite
- **Styles**: CSS3 Custom Properties & Modern Gradients

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
